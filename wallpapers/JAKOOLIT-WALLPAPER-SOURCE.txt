Source: https://github.com/JaKooLit/Wallpaper-Bank/tree/main/wallpapers

This folder contains the repository's top-level static wallpaper files.
The Dynamic-Wallpapers directory was intentionally excluded.

The repository notes that these wallpapers are collected from sources such as
Alphacoders, Wallhaven, and Wallpaper-clan and are not authored by JaKooLit.
Refer to the upstream repository and original sources for ownership and usage terms.
